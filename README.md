## 目录结构 / Structure

- `index.html` —— 站点本体（单文件：HTML + CSS + JS）
- `mobile.html` —— 手机竖屏预览壳（手机端打开会自动跳回 `index.html`）
- `assets/hero-silvade.mp4` —— 首页主视觉视频
- `assets/commissions-gallery/` —— 委托稿件（每组 `full/` 大图 + `thumbs/` 缩略图）
- `assets/fursuit-gallery/` —— 兽装照片（同上）
- `assets/fonts/` —— 自托管字体（Inter / Noto Sans SC / Noto Serif SC，OFL 许可，附 LICENSE 文件）
- `favicon.ico` / `favicon-32.png` / `apple-touch-icon.png` —— 站点图标
